# PC Builder — пошаговая инструкция разработки

## Как пользоваться этим файлом

Иди строго сверху вниз. Не создавай файлы «на будущее», пока инструкция до них не дошла. После каждого пункта открывай страницу в браузере и проверяй результат.

Твоя папка проекта:

```text
C:\OSPanel\domains\php-kursovaya
```

Адрес проекта в браузере:

```text
http://php-kursovaya/
```

Сейчас в проекте есть только два макета:

- `главная.png` — макет главной;
- `каталог.png` — макет каталога.

Мы сначала создадим рабочий каркас, затем подключим базу данных, и только потом сделаем корзину и заказы.

---

# Этап 1. Первый рабочий PHP-файл

## Шаг 1. Создай `index.php`

Создай файл прямо здесь:

```text
C:\OSPanel\domains\php-kursovaya\index.php
```

Вставь код:

```php
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>PC Builder</title>
</head>
<body>
    <h1>Интернет-магазин комплектующих</h1>

    <p>Это учебный проект на PHP.</p>

    <a href="catalog.php">Перейти в каталог</a>
</body>
</html>
```

Открой:

```text
http://php-kursovaya/
```

Если видишь заголовок — PHP-файл и OpenServer работают.

## Что здесь нужно понять

- `<!DOCTYPE html>` сообщает браузеру, что это HTML5.
- `<head>` содержит настройки страницы.
- `<body>` содержит то, что видит посетитель.
- `href="catalog.php"` ведёт на файл в той же папке.
- PHP пока не использован — это нормально. Сначала создаём HTML-каркас.

# Этап 3. Подключаем CSS и шрифт

## Какой шрифт выбрать

Для этого макета берём **Manrope**:

- он современный и хорошо подходит для магазина техники;
- у него аккуратные цифры для цен;
- он похож по настроению на шрифт в макетах;
- одного шрифта достаточно для всего сайта, поэтому проект не будет перегружен.

Не подключай сразу много шрифтов. Для нашего проекта используем:

```text
Manrope, sans-serif
```

## Шаг 1. Подключи Google Fonts

В файле `index.php` внутри `<head>` добавь эту строку **до своих CSS-файлов**:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&display=swap" rel="stylesheet">
```

Сейчас твой `<head>` должен выглядеть примерно так:

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&display=swap" rel="stylesheet">

    <link rel="stylesheet" href="assets/css/reset.css">
    <link rel="stylesheet" href="assets/css/style.css">

    <title>PC Builder</title>
</head>
```

Почему сначала подключаются шрифты, а потом CSS: CSS должен получить доступное семейство `Manrope`, когда задаёт его элементам.

Если интернет отключён, Google Fonts не загрузится. Для учебного проекта пока этого достаточно. Позже, если понадобится полностью автономный сайт, скачаем файлы шрифта и подключим их через `@font-face`.

## Шаг 2. Создай `assets/css/style.css`

Если файла ещё нет, создай его здесь:

```text
C:\OSPanel\domains\php-kursovaya\assets\css\style.css
```

```css
:root {
```

Проверь шрифт: временно добавь в `<body>`:

```html
<h1>Проверка шрифта Manrope</h1>
<p>Процессор AMD Ryzen 7 7800X3D — 37 990 ₽</p>
```

У заголовка и текста должна измениться форма букв. После проверки этот тест можно удалить.

# Этап 4. Учимся использовать PHP-массивы

## Шаг 1. Добавь PHP в начало `index.php`

Самой первой строкой файла, до `<!DOCTYPE html>`, напиши:

```php
<?php
$shopName = 'PC Builder';
$pageTitle = 'Интернет-магазин комплектующих';

$categories = [
    'Процессоры',
    'Видеокарты',
    'Материнские платы',
    'Оперативная память',
    'Накопители',
    'Блоки питания',
    'Корпуса',
];
?>
```

## Шаг 2. Используй переменные в HTML

Замени `<title>`:

```php
<title><?= $shopName ?></title>
```

Замени `<h1>`:

```php
<h1><?= $pageTitle ?></h1>
```

`<?= ... ?>` выводит значение PHP в HTML.

## Шаг 3. Выведи категории циклом

После абзаца добавь:

```php
<h2>Категории</h2>

<ul>
    <?php foreach ($categories as $category): ?>
        <li><?= $category ?></li>
    <?php endforeach; ?>
</ul>
```

Проверь страницу. На ней должен появиться список из семи категорий.

## Что нужно понять

- `$categories` — массив данных.
- `foreach` проходит по каждому элементу.
- `$category` — текущая категория в конкретной итерации.
- `endforeach` закрывает альтернативную запись цикла.

# Этап 5. Создаём общую шапку

Чтобы не копировать шапку на каждой странице, создаём файл:

```text
app/views/header.php
```

В него позже вынесем общую шапку. Сейчас создай файл с таким кодом:

```php
<header class="site-header">
    <div class="container site-header__inner">
        <a class="logo" href="index.php">PC BUILDER</a>

        <nav class="main-nav">
            <a href="catalog.php">Каталог</a>
            <a href="index.php">Главная</a>
            <a href="contacts.php">Контакты</a>
        </nav>

        <a href="cart.php" class="cart-link">Корзина</a>
    </div>
</header>
```

Добавь в `assets/css/style.css`:

```css
.site-header {
    background: var(--color-black);
    color: var(--color-white);
}

.site-header__inner {
    min-height: 72px;
    display: flex;
    align-items: center;
    justify-content: space-between;
    gap: 24px;
}

.logo {
    color: var(--color-white);
    font-weight: 700;
    text-decoration: none;
}

.main-nav {
    display: flex;
    gap: 24px;
}

.main-nav a {
    color: var(--color-white);
    text-decoration: none;
}

.main-nav a:hover {
    color: var(--color-orange);
}

.cart-link {
    color: var(--color-white);
    text-decoration: none;
}
```

В `index.php` сразу после `<body>` подключи шапку:

```php
<?php require __DIR__ . '/app/views/header.php'; ?>
```

`__DIR__` означает папку текущего файла. `require` подключает содержимое другого PHP-файла.

# Что делать прямо сейчас

Выполняй только эти пункты:

1. Создай `index.php` из этапа 1.
2. Создай папки и `assets/css/style.css`.
3. Подключи CSS и сделай оранжевую кнопку.
4. Добавь PHP-массив категорий и цикл `foreach`.
5. Создай `app/views/header.php`.
6. Создай `catalog.php`.
7. Проверь оба адреса:
   - `http://php-kursovaya/`
   - `http://php-kursovaya/catalog.php`

Не переходи к базе данных, пока эти два адреса не открываются без ошибок.

# Следующий этап после проверки каркаса

Когда каркас будет готов, создадим базу данных:

```text
database/schema.sql
database/seed.sql
```

Таблицы будут добавляться в таком порядке:

1. `categories`;
2. `products`;
3. `product_images`;
4. `reviews`;
5. `orders`;
6. `order_items`;
7. `contacts_messages`.

После этого подключим базу через `PDO`, выведем реальные товары и уберём тестовый массив из `index.php`.

# Правила, чтобы не запутаться

- Один шаг — одна проверка в браузере.
- Не вставляй код из следующего этапа раньше времени.
- Не храни цену товара в корзине из данных браузера: цену всегда берём из базы.
- Все значения пользователя позже будем проверять и экранировать.
- `shadcn` нам не нужен: красивый интерфейс сделаем обычными CSS-компонентами.
- Если появляется ошибка, присылай полный текст ошибки и файл с проблемой.
